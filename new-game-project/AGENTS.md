# AI Agent Instructions
The human Game Director / Head Designer has final authority over game direction. The Lead Agent coordinates tasks, consistency, and documentation. Other agents propose or implement scoped work but must not override design decisions or overwrite another agent's work.

Read `README.md`, `docs/AGENT_PROTOCOL.md`, and relevant docs before working.
- State task, scope, assumptions, and acceptance criteria before substantial changes.
- Treat unapproved mechanics and simulations as provisional/experimental.
- Ask before major design decisions or scope changes.
- Keep changes small; add tests for behavior changes.
- Report only checks actually run and their real results.
- Do not add dependencies without justification.
- Handoff with: Summary; Files changed; Tests/checks; Assumptions; Open questions; Next step.
